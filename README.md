# RecetaViral - Generador de Recetas Estilo TikTok

PWA instalable bilingüe (Español / Inglés) con recetas basadas en tendencias de FoodTok 2026.

## Características

- Genera recetas a partir de los ingredientes que tienes en casa
- Filtros: Fáciles, Alto proteína, Menos de 30 min, Virales TikTok
- Receta sorpresa
- Plan de comidas de 7 días
- Lista de la compra inteligente
- Cambio de idioma ES ↔ EN
- Funciona offline (Service Worker)
- Instalable como app en móvil y escritorio

## Cómo desplegarlo gratis en GitHub Pages

1. Crea una cuenta en [github.com](https://github.com) si no tienes.
2. Crea un repositorio nuevo llamado `recetaviral` (o el nombre que quieras).
3. Sube **todo el contenido** de esta carpeta a la raíz del repositorio:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - carpeta `icons/`
   - este `README.md`
   - el archivo `.nojekyll`
4. Ve a **Settings → Pages**.
5. En **Source** selecciona **Deploy from a branch**.
6. Branch: `main` (o `master`) y folder: `/ (root)`.
7. Guarda. En 1-2 minutos tu app estará online en:
   `https://tuusuario.github.io/recetaviral/`

## Cómo instalarla en el móvil

1. Abre el enlace de GitHub Pages en Chrome o Safari.
2. En Android: menú → **Añadir a la pantalla de inicio** o **Instalar app**.
3. En iPhone: botón compartir → **Añadir a la pantalla de inicio**.
